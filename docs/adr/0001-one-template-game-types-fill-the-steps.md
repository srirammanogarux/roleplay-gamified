# One template; a game type only changes what's inside the steps

Every roleplay runs the same steps in the same order: story, face-off, mission, conversation (one spoken turn at a time), results. A game type (Saying no, Confessing, Small talk, Being blamed…) only changes what fills those steps: the meter, the clock, the special moment, the endings, how stars are earned. So a new roleplay is a new roleplay file plus, at most, one new meter or moment, never new screens. We chose this over letting each game type shape its own flow because five roleplays for one demo, and many more after it, are only affordable if the engine is built once and writing and assets are the only per-roleplay cost.

## Consequences

- If an idea needs a new step, or a new way to answer (e.g. picking from options instead of speaking), it's a new template, not a new game type. Negotiate is the first expected case: its "deal dial" and back-and-forth offers are planned as template #2, after the demo.
- A roleplay has exactly one game type. A situation that turns into a second game partway through (confess, then say no to staying late) is split into two roleplays.
